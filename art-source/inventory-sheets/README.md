# Generated Inventory Sprite Sheets

These three original 4×4 sheets were generated for The Chosen Quest using the
Ravenmore Fantasy Icon Pack only as a broad reference for compact silhouettes,
hand-painted materials, warm highlights, cool shadows, and readability against
a dark game interface. No Ravenmore icon was copied into these sheets.

Reference: https://opengameart.org/content/fantasy-icon-pack-by-ravenmore-0

The production sheets in `assets/icons/inventory-sheets/` are 1280×1280 RGBA
PNGs. Each cell is exactly 320×320 pixels. Coordinates below are zero-based.
