# The Chosen Quest Enhanced — 0.7.0-beta.1

This is the first update-aware private beta and the baseline for testing future
in-game update notifications.

## Highlights

- Rebuilt character creation around one live hero showcase with gender artwork,
  race crests, starting-loadout choices, build guidance, and fantasy name generation.
- Introduced the painterly fantasy Art Deco visual system with modular class color
  and subtle race heraldry across hero-owned surfaces and branded tester materials.
- Expanded tactical class resources, weapon traits, status feedback, equipment
  comparison, vendor specialization, loot tiers, and elite relic identification.
- Expanded the fog-aware map, full-map overlay, objective and rumor presentation,
  roaming threats, finite Spider Nest, and Ashweb Matriarch elite finale.
- Added non-blocking update checks, a manual Settings action, and a styled update
  overlay with Download, View Changes, and Remind Me Later.
- Continued stability, large-screen layout, image-loading, audio, and accessibility
  refinements across exploration, shops, inventory, and combat.

## Update-test baseline

1. Install and keep this exact `0.7.0-beta.1` folder.
2. Open Settings and choose **Check Updates**. It should report this version as current.
3. After `0.7.0-beta.2` is published, relaunch this older copy while online.
4. Verify the update notice, release information, reminder behavior, and official
   GitHub download handoff.
5. Launch once without internet access. The game must remain fully playable.

This phase never overwrites the installation or save data. Downloading opens the
official GitHub release in the system browser.
